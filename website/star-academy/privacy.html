01

Who this covers

This policy is published by Wholesale Omniverse LLC for the Pinterest account and Amazon Influencer storefront operated under the name Star Academy — live at amazon.com/shop/star-academy06 (also reachable at Amazon’s raw storefront link, amazon.com/shop/influencer-62d56ca7 — both point to the same storefront). It governs one system: an automation tool that curates products for that storefront, drafts Pinterest pin copy, and posts to Star Academy’s own Pinterest boards on the account holder’s behalf.

There is no separate Star Academy website, login system, or user-facing app that this policy needs to cover — if that changes, this policy will be expanded and re-dated accordingly.

02

Pinterest data we access

The integration authenticates once via Pinterest’s OAuth flow and is granted the following scopes, used only against the Star Academy account that authorized them:

ScopeWhat it’s used for
boards:readListing existing boards to route new pins by product category.
boards:writeCreating a new board when a product category has none yet.
pins:readChecking recent pin history to avoid re-posting the same product too soon.
pins:writePublishing new pins to Star Academy’s boards.
user_accounts:readConfirming the token belongs to the correct Star Academy account.
03

How that data is used

Board and pin data retrieved through the API is used only to:

  • Decide which board a new pin should post to, based on product category.
  • Avoid duplicate or overly frequent posting to the same board or image.
  • Generate a weekly performance summary (impressions, saves, outbound clicks) so the storefront curation can prioritize what’s working.

None of this data is used to build advertising profiles, is sold, or is used for any purpose beyond operating Star Academy’s own storefront presence on Pinterest.

04

Amazon affiliate links

Products featured in pins are drawn from the Star Academy Amazon Influencer storefront at amazon.com/shop/star-academy06. Pins link to those product listings on amazon.com using standard Amazon Associates tracking links (a tag= parameter appended to a direct, unmodified Amazon URL). Clicking a pin sends you to Amazon directly — the link is never cloaked, shortened through a third party, or routed anywhere other than Amazon’s own domain. Amazon’s handling of any data collected once you land on amazon.com is governed by Amazon’s own Privacy Notice, not this one.

As required by the Amazon Associates Program, every pin using an affiliate link is disclosed as such (“As an Amazon Associate I earn from qualifying purchases” or the short-form #CommissionsEarned).

05

Storage & retention

The Pinterest access token and a log of posted pins (title, description, destination link, and post time) are stored in a private data store operated by Wholesale Omniverse LLC — not in any public-facing database, and not accessible to anyone outside the account operator. Pin logs are retained to support the duplicate and cadence checks described in Section 3 and are periodically pruned.

06

Sharing with third parties

Pinterest data accessed through this integration is not sold, rented, or shared with any third party. The only outbound calls this system makes are to Pinterest’s own API (to post pins and read analytics) and, optionally, to Anthropic’s Claude API to draft pin copy — no Pinterest account data is included in that copy-drafting call beyond the product details Star Academy itself curated.

07

Your controls

Because this integration operates a single business account rather than end users, controls sit with the Star Academy account holder:

  • Revoke API access at any time from Pinterest’s Apps settings — this immediately invalidates the token.
  • Any pin can be deleted directly from Pinterest, the same as any manually created pin.
  • Request deletion of the stored pin log by contacting us (Section 10).
08

Security

The Pinterest access token is stored as an environment variable, not committed to source control, and is never logged in plaintext. Only the account operator has access to the systems running this integration.

09

Changes to this policy

If Star Academy adds a public-facing website, app, or any flow that collects data from visitors, this policy will be revised to cover it and the effective date at the top will be updated. Material changes will be reflected here before they take effect.
